基于大语言模型的高校图书馆智能参考咨询服务构建与应用研究――以山东大学图书
馆为例*1

富国瑞  王平利  王一展  宋西贵（山东大学图书馆）

摘要 随着人工智能技术的快速发展，高校图书馆亟需创新参考咨询服务模式。本文提出一种结合

“预训练模型+本地知识库”的解决方案，构建了基于大语言模型的智能参考咨询服务系统。该系统

通过数据资源层、模型训练层、应用服务层和交互展示层的有机结合，增强了智慧图书馆的人机协

同和人智协同能力。以山东大学图书馆为例，详细阐述了该系统在管理服务、空间服务、资源服务

等多个场景中的具体应用及效能评估结果。研究表明，该系统在提升服务效率、优化用户体验方面

具有显著优势，能够提供更全面、更详细、更个性化的咨询服务，为高校图书馆开展智能化服务提

供了新的解决思路和实践路径。

Research  on  the  Construction  and  Application  of  Intelligent  Reference  Service  in

University  Libraries  Based  on  Large  Language  Model――Taking  Shandong  University

Library as an Example

Fu Guorui, Wang Pingli, Wang Yizhan, Song Xigui（Shandong University Library）

Abstract    With  the  rapid  development  of  artificial  intelligence  technology,  university  libraries  need  to

innovate the reference service mode. This paper proposes a solution combining "pre-training model + local

knowledge base" to build an intelligent reference service system based on big language model. Through the

organic combination of data resource layer,  model training layer, application service layer and interactive

display layer, the system enhances the human-computer collaboration and human-intelligence collaboration

capabilities  of  intelligent  libraries.  Taking  the  library  of  Shandong  University  as  an  example,  this  paper

elaborates the specific application and effectiveness evaluation results of the system in management service,

space  service,  resource  service  and  other  scenarios.  The  research  shows  that  the  system  has  significant

advantages  in  improving  service  efficiency  and  optimizing  user  experience,  and  can  provide  more

comprehensive,  more  detailed  and  more humanized  consultation  services,  which  provides  a new  solution

and practice path for university libraries to carry out intelligent services.

2 LLM 为图书馆参考咨询服务带来的机遇和挑战

2.1 机遇

（1）个性化服务。智能聊天机器人可以处理多轮对话，深入挖掘用户需求，结合知识图谱技术，

LLM 能够实现智能推荐和个性化信息推送。

（2）多模态交互。结合计算机视觉和自然语言处理技术，LLM 可实现图文音视频等多种形式

的交互。多模态 LLM（如 GPT-4o）可以理解和处理图像、音频等多种形式的信息[17]，为视障用户

提供无障碍服务。

（3）跨语言服务能力。多语言 LLM（如 DeepL[18]）具备出色的跨语言理解和翻译能力，有助

于图书馆为国际学生提供更好的服务，促进全球学术交流。

2

2.2 挑战

（1）数据隐私与安全。LLM 的训练和使用涉及大量敏感数据，图书馆需要建立严格的数据治

理框架，确保用户隐私得到保护。

（2）准确性与可解释性。尽管 LLM 性能不断提升，但仍存在幻觉和错误信息的风险。图书馆

需要建立有效的质量控制机制，并探索可解释人工智能技术，以提高 LLM 决策过程的透明度。

（3）人机协作模式。需要探索图书馆员与 AI 系统的最佳协作方式，培养馆员 AI 素养和数据分

析能力[19]。通过设计人机协作的工作流程，充分发挥人类专业知识和 AI 效率的优势。

（4）伦理与公平性。LLM 可能存在偏见和歧视问题。图书馆需要制定 AI 伦理准则，确保 LLM

的公平性和包容性，防止加剧信息鸿沟。

（5）基础设施与成本。部署和维护先进 LLM 系统需要大量计算资源和专业技能，这对许多图

书馆的预算和技术能力提出了挑战。

LLM 为高校图书馆参考咨询服务带来了革命性的机遇，但同时也面临着多方面的挑战。图书馆

需要制定全面的 AI 战略，平衡创新与风险，确保 LLM 的负责任和有效应用。

3 图书馆 LLM 智慧参考咨询的构建

3.1 LLM 智慧参考咨询基本原理

LLM 通常基于 Transformer 算法架构，通过无标注文本数据进行预训练，基于有监督微调[20]、

人类偏好与反馈强化学习[21]、人类对齐[22]等关键技术，展现出显著的泛化和推理能力，支持零样本

或少样本学习，随着模型参数和训练数据的增加，出现了涌现能力[23]，问答服务得到有效回复，使

智慧参考咨询成为可能。

LLM 的涌现能力，大大加强了场景化的智慧参考咨询的可用性，包括上下文学习[24]、思维链[25]

和指令学习。操作人员无需手动更新模型参数，便能轻松学习输入样本中的模式，这一优势大大降

低了学习成本，使得语言模型即服务[26]的概念变得切实可行，从而推动了上下文学习的实现。思维

链作为一种常用的提示策略，能够有效提升大型语言模型在推理方面的能力，它引导模型生成连贯

的中间推理步骤，进而在处理复杂推理任务时展现出更为卓越的表现。指令学习能力，则是指 LLM

能够根据用户输入的自然语言指令，准确、高效地执行特定任务，这一能力进一步增强了模型的实

用性和用户体验。图书馆智慧参考咨询 LLM 基于“预训练模型+本地知识库”构建咨询系统，是提

升模型处理自然语言文本能力的关键，既发挥模型生成内容的智能性，同时保障生成内容的规范性

3.2LLM 智慧参考咨询系统框架

针对高校图书馆咨询服务的实际需求，构建一个高效、智能的参考咨询 LLM 系统显得尤为重要。

以构建 LLM 智慧参考咨询为目标，通过领域数据集对垂直领域模型进行微调及协同，进而支撑图书

馆专业咨询服务[28]。本文设计了包括数据资源层、模型训练层、应用服务层、交互展示层 4 个层面

的系统框架，如图 1 所示。

3.2.1 数据资源层

业务流程、服务报告、大事记、年鉴等；网络数据，数据库、OA 数据及网络开放的相关数据。所

有数据汇聚到图书馆大数据中心，个别数据通过 API 接口直接注入 LLM 数据池，敏感数据要经过

脱敏、加密处理，以确保数据使用合法、合规、安全可靠。收集到的数据需要经过清洗、标注、提

3.2.2 模型训练层

模型训练层是构建 LLM 的核心，负责对数据资源层提供的数据进行模型的训练和优化，基于本

地知识库、上下文学习、指令微调等对模型进行训练，实现模型的逐步优化和提升，通过接口模块

与应用层进行互动交流。本文选择“预训练模型+本地知识库”架构，通过自注意力机制捕捉文本中

的长距离依赖关系，并且使标签（token）并行计算。通用接口 API 对各个模块进行接口封装，在统

一标准接口适配下，模块间以统一的标准驱动不同的领域模块协调运行。基于参考咨询服务领域文

本数据构建本地知识库，与 LLM 结合解决大模型特定领域知识的问题；通过向量数据库，依据咨询

问题在领域知识库中找到相关内容，再利用大模型的泛化和推理能力及对各类指令的适应性生成回

复[29]。

为了激发模型理解、适应人类意愿和解决问题的能力，需对模型进行微调，实现 LLM 与人类偏

好的对齐，加速模型的训练过程并提高性能，使 LLM 能够适应参考咨询服务领域的特定任务和知识，

以实现普遍任务解决能力。基于有监督微调方法，利用人类偏好一致的指令数据训练大模型，激发

语言模型的深层次理解能力；基于人类反馈的强化学习算法，训练出一个奖励机制，利用强化学习

来优化学习过程。使模型在不断学习新数据的同时保持对旧数据的记忆能力，通过高质量数据训练，

将知识整合到 LLM 中，以适应知识的不断更新和演变。

为了验证模型的有效性还需对模型进行评估，模型性能评估一般采用预训练模型评估和检索增

强生成（RAG）方向的评估。预训练模型评估一般采用公开数据集或者自建测试数据集，公开数据

集如 MMLU[30]、C-Eval[31]、GSM8K[32]、HumanEval[33]等，通过测试模型的准确性以衡量模型推理

能力及生成能力。

3.2.3 应用服务层

应用服务层是将 LLM 应用于实际场景的关键，是在模型训练层和数据资源层提供支撑基础上，

通过标准化接口构建参考咨询服务，提供多样化、个性化的服务，以满足用户学术咨询、文献推荐、

语义搜索等不同需求。用户通过自然语言提问，系统能够理解并生成相应的回答或解释；系统可以

根据用户的兴趣偏好和历史行为推荐相关的文献信息、资源服务，帮助用户发现更多有价值的资源；

5

系统能够更准确地理解用户的查询意图，并返回更精确、更全面的搜索结果。应用服务层需要具备

灵活的服务接口和强大的处理能力，服务接口能支持与其他系统的集成与交互，以实现服务的广泛

应用和共享，处理能力需要采用高性能的计算资源和优化的算法设计，以确保服务的响应速度和稳

定性。应用服务层可以创建基于 LLM 的低代码平台，帮助图书馆员在没有编程基础的情况下快速构

建相关应用，让更多的图书馆馆员参与到构建智慧参考咨询服务系统中。

3.2.4 交互展示层

交互展示层是用户与 LLM 进行交互的窗口，用户以自然语言方式与系统进行交互，提供直观、

友好的用户界面和丰富的交互功能，具有良好的用户体验和便捷的交互方式，以降低用户的使用门

槛并提高满意度。在交互展示层中，需要设计简洁明了的用户界面和符合用户习惯的操作流程，还

需要支持丰富的交互功能，如自然语言输入、实时反馈、结果可视化等。自然语言输入功能允许用

户以自然语言的形式输入问题或需求，提高输入的灵活性和便捷性。实时反馈功能则可以及时向用

户展示处理进度和结果，增强交互的实时性和响应性。结果可视化功能则能够以图表、摘要等形式

展示模型生成的结果，帮助用户更清晰地理解和利用信息。

本文设计的 LLM 智慧参考咨询框架，通过不同的应用模块相互关联和协作，构建一个便捷、高

效、智慧参考咨询系统，为高校师生提供优质的学术支持和服务体验，可进一步促进图书馆行业在

LLM 方面的探索、研究和应用。

以达到更好的问答效果。（4）对话管理：支持对大模型进行回复设置和编辑回复内容。

容进行微调完善，与传统的向量库预设答案相比，有效提升了咨询服务的人性化、交互性和智能性。

5 结论与展望

本文基于分析大语言模型为参考咨询带来的机遇和挑战，通过构建基于“预训练模型+本地知识

库”相结合方案实现了智慧参考咨询服务的实践应用，探讨了大模型基本原理、系统框架、工作流

程，探索 LLM 赋能图书馆参考咨询服务的应用场景、实践效能。

本文利用 AI 技术赋能图书馆创新发展，提供多场景、多模态泛化服务，提升智慧图书馆人机协

同、人智协同能力，进而促进图书馆服务范式的转变，加速新兴技术在图书馆的深度融合。系统设

计希望能为图书馆参考咨询服务的创新发展提供参考，本文存在服务效能挖掘不足、输出精准性进

一步优化等相关问题，将在后续的研究中进一步完善和提升。
